# P5 Phantom Companion 1.3.0

搭配 P5 · Open Tear 1.5.0，提供 Classic/Night 切换、原生菜单轮盘、头像调节和桌面位置记忆。

## 安装与更新

已通过本仓库安装的用户，在酒馆扩展管理中更新 P5 Phantom Companion，然后刷新页面即可。1.3.0 新增的 controls.js 会随更新一起获取，无需另装第二份。

首次安装，在酒馆“扩展 → 安装扩展”中填写：

https://github.com/demilich1117/p5-phantom-companion

请另行导入 Open Tear 1.5.0 主题 JSON，以使用新版头像调节、可移动战车轮盘和完整美化。扩展更新不会替换主题；阅读布局、撕纸头像、塔罗图片和图标造型由主题提供。

## 使用

- 桌面点击 COMMAND 展开轮盘，选菜单、点击外部或 Escape 收起。拖动战车塔罗移动轮盘；COMMAND 入口也能拖动。
- 聚焦塔罗后用方向键移动，Shift 加速，Home 复位；入口同样支持键盘移动。扩展设置里可以一起重置两处位置。
- 扩展 → P5 / PHANTOM CONTROLS 中，分别调角色与用户头像：横幅高度 75–150%，横向/竖向取景 0–100%。竖向数值越小，越靠原头像顶部；默认 30%。点击“跟随主题默认值”撤销该类头像的扩展覆盖。
- 这些设置适用于本用户的 P5 主题，角色项影响全部角色消息，用户项影响全部用户消息；不是逐角色的人脸识别或角色卡修改。
- 显示模式可选跟随主题、Classic、Night、跟随系统。旧版的配色选择保留。
- 手机继续使用原生顶部菜单条，头像设置同样可用。拖动入口与轮盘仅在桌面显示，位置以窗口比例保存，缩放窗口后自动留在可见范围。

## 宿主与数据

最低 ST 兼容版本 1.18.0，实际验证 ST 1.19.0（749441e）。TT 沿用 ready/context、1000px 移动断点与安全区适配；本轮没有真实 TT WebView 验收。

纯前端扩展，不读取聊天或角色，不调用模型，无额外网络服务。只保存自身显示偏好，原生菜单与头像内容由酒馆管理。停用或切换其他主题时清理控件及运行时变量。
